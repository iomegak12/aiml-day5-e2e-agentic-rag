# Code of Conduct

## Our Pledge

We pledge to make participation in this project and its learning community a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected Behaviour

- Be respectful and constructive, especially when reviewing others' work.
- Welcome questions. Everyone is here to learn.
- Accept feedback gracefully and give it with care.
- Focus on what is best for the community.

## Unacceptable Behaviour

- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, and trolling.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This code applies to every project space: issues, pull requests, reviews, discussions about the course material, the agent, the REST API, the web UI and the MCP server, and anywhere you represent the project.

## Enforcement

Report incidents to **jd.ramkumar@gmail.com**. Every report is reviewed promptly and kept confidential. The maintainer may remove, edit or reject contributions, or temporarily or permanently ban participants, for behaviour that violates this code.

Based on NetCore SD-WAN configuration guide (KB-NET-1010) and Meet Media Troubleshooting (KB-MTG-2006), apply the following policy adjustments:

1. Apply SLA class Gold-Voice

menu_book KB-NET-1010 · p.3

Branch routers provisioned with default Best-Effort transport degrade RTP packet handling under cellular or high-load MPLS failover. Transition tunnel steering to SLA-GOLD-VOICE to enforce dynamic multi-path rerouting before jitter cascades into session termination.

2. QoS: mark voice EF (DSCP 46)

Map bi-directional voice streams into Expedited Forwarding with strict low-latency queuing (LLQ). Ensure priority bandwidth reservation guarantees at minimum 30% capacity with jitter tolerance set below <10ms and packet loss bounded strictly below <0.5%.

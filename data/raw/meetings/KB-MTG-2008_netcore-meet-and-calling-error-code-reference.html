NetCore Meet and Calling Error Code Reference

KB-MTG-2008 | NetCore Meet 5.0 | Last updated: 2026-09-30 | Status: current

Summary

This reference lists all current MTG error and alarm codes for NetCore Meet 5.0 and related NetCore Calling integration scenarios. Use it to map each code to the affected component, likely cause, recommended user action, administrator action, and related troubleshooting article.

Applies to: NetCore Meet 5.0, NetCore Meet desktop app for Windows and macOS, NetCore Meet mobile app, NetCore Meet web client, NetCore Calling integration, NetCore Control Hub

Overview

MTG codes identify user-facing errors, meeting media alarms, SSO authentication failures, and Calling integration provisioning issues. In NetCore Meet 5.0, the same code format is used across the desktop app, mobile app, web client, meeting diagnostics, and NetCore Control Hub event views.

When triaging an incident, record the exact code, timestamp, affected user, meeting ID or Calling number, client type, and network path. For join and media issues, verify that TCP 443 is available for signalling, UDP 9000 is available for preferred media transport, and TCP 5004 is available for media fallback. Recommended network targets are latency less than 300 ms, jitter less than 40 ms, and packet loss less than 3%.

The table below covers every current MTG code in this release: MTG-JOIN-1003, MTG-JOIN-1007, MTG-MED-4102, MTG-MED-4105, MTG-SSO-6001, MTG-SSO-6004, MTG-CALL-7002, and MTG-CALL-7010.

Notes on interpretation

Do not treat all MTG codes as service outages. MTG-JOIN-1003 can be expected behavior when a meeting is locked or when an external participant is waiting in the lobby. By contrast, repeated MTG-JOIN-1007 events from the same subnet usually indicate a firewall or proxy path issue.

For MTG-MED-4102, compare diagnostics against the NetCore Meet 5.0 recommendations: latency less than 300 ms, jitter less than 40 ms, and packet loss less than 3%. A meeting can remain connected while this alarm is active, but user experience may include frozen video, robotic audio, or delayed screen sharing.

For MTG-MED-4105, separate device detection from media transport. If no audio device is detected, opening UDP 9000 or TCP 5004 will not resolve the error; investigate operating system device visibility, client permissions, and headset state first.

For MTG-SSO-6001 and MTG-SSO-6004, the user action is intentionally limited because the source of truth is the SAML configuration. Administrators should validate NetCore Control Hub SSO settings against the identity provider configuration as described in KB-MTG-2001.

For MTG-CALL-7002 and MTG-CALL-7010, check Calling configuration in the same tenant context as the Meet user. Confirm E.164 number provisioning, location assignment, location-based dial plans, optional outbound prefix 9 policy, and emergency address completeness before retesting.

  • Use KB-MTG-2007 for join failures involving MTG-JOIN-1003 or MTG-JOIN-1007.
  • Use KB-MTG-2006 for audio and video quality incidents involving MTG-MED-4102 or endpoint audio symptoms related to MTG-MED-4105.
  • Use KB-MTG-2001 for SAML configuration issues involving MTG-SSO-6001 or MTG-SSO-6004.
  • Record the exact error code verbatim in case notes: MTG-JOIN-1003, MTG-JOIN-1007, MTG-MED-4102, MTG-MED-4105, MTG-SSO-6001, MTG-SSO-6004, MTG-CALL-7002, MTG-CALL-7010.
